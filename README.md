# استودیو رف

سازنده‌ی قالب مربعی محصول با خروجی PNG در ابعاد ۱۰۸۰×۱۰۸۰. تمام پردازش تصویر داخل مرورگر انجام می‌شود و فایلی به سرور ارسال نمی‌شود.

## اجرای محلی

```bash
python3 -m http.server 4173
```

سپس `http://localhost:4173` را باز کنید.

## انتشار در Vercel

این پروژه استاتیک است و Build Command لازم ندارد. پوشه را به یک مخزن Git متصل کنید و در Vercel ایمپورت کنید؛ تنظیمات پیش‌فرض کافی است.

## فونت و لوگو

- فونت Dana از مسیر `assets/fonts` به‌صورت محلی بارگذاری می‌شود.
- برای عوض‌کردن لوگوی پیش‌فرض، فایل نسخه‌دار داخل `assets/images` را جایگزین و نام آن را در `index.html` و `app.js` به‌روزرسانی کنید تا کش مرورگر شکسته شود.
- برای افزودن Vazir، فایل‌های آن را در `assets/fonts` قرار دهید و یک `@font-face` مشابه Dana در ابتدای `styles.css` اضافه کنید.
